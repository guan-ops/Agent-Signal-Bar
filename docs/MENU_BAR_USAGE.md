# 菜单栏用量摘要

系统菜单与卡片面板均不使用内嵌滚动容器，按内容自然确定高度；共用 `MenuUsageSummaryView`：平台切换、当前账号与套餐、配额剩余比例与重置时间、今日／近 30 天双列 Token 与估算费用、固定显示 Token 的近 30 天柱状图。柱状图读取现有扫描结果，随平台切换；悬停显示当天 Token 和估算费用，详情行固定高度，避免菜单跳动。两处都显示扫描进度，并保留旧结果。缺失用量显示破折号；失败与上次读取结果明确标注。Codex 的来源、账号上下文与限制 ID 继续保留，本地观察单独标识，不跨来源合并。

系统菜单通过系统“切换账号”子菜单操作，卡片面板使用账号按钮。Claude 保存账号来自可选 cswap。点击“用量与账号设置”或“管理账号”会跳到对应平台的用量页。菜单与设置共用 ClaudeSupportModel，不创建独立账号快照。菜单关闭会释放系统菜单宿主，停止其定时刷新。

卡片面板保留监控控制，运行记录通过设置窗口查看。更详细的历史模型拆分、专项配额及认证配置留在设置页。

此前验证使用隔离模型、虚构账号与扫描 fixture；已检查系统菜单的平台切换、系统账号子菜单、Codex/Claude 设置跳转，以及卡片面板的配额和扫描进度。这些验证未执行真实账号切换。本次柱状图增补已通过 macOS 构建检查，并重新编译启动本地 App；未发布版本。

本次无滚动布局通过 16 项相关测试，并以虚构账号和 30 天数据渲染验收：验证两种菜单的宽高、完整内容尺寸以及没有 NSScrollView。系统菜单的宿主在内容变化时同步高度，悬停详情保持固定高度。

## 设置中的 Codex 项目与会话明细

设置 → 用量 → Codex 的 Token 图表下方显示近 30 个自然日的项目与会话。项目按完整日志路径区分（同名目录不合并），按 Token 降序排列；点击项目筛选会话，可搜索路径、会话 ID 与模型，并分批展开列表。项目与会话默认收起，只显示数量；整行标题（箭头、文字、数量及空白区域）均可点击展开或收起，支持按钮键盘操作；展开后分别显示 3 个项目和 5 个会话，每次“显示更多”追加相同数量，收起后恢复首批数量。会话显示模型、输入、缓存、输出、总 Token、最近用量事件时间和估算费用。缓存 Token 已包含在输入中；未知费用显示破折号，部分定价合计显示 ≥。

明细复用已确认的 Codex 扫描缓存及定价逻辑，排除重复副本、冲突来源、Pi 导入和未完成扫描的实时用量，不归属于所选账号。项目仅从有大小上限的 session_meta 头读取 cwd；头不可读或身份不匹配归入“未识别项目”。成功扫描后替换明细，失败保留上次结果；明细不参与实时计数吸收，因此实时总量仍在核对时也能显示已确认的历史及扫描时间。此功能当前对应 Codex 本地日志。

设置中的 Token 图表在下方保留适量留白与提示；悬停详情在该区域内展开，高度只根据当前日期的内容自然增减，不预留所有日期的最大高度，也不显示浮层或系统工具提示。移过柱形间隙时保留当前详情，离开整个柱形区域后恢复留白，避免间隙触发反复收起。
