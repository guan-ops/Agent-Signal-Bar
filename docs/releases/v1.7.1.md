# Agent Signal Bar v1.7.1

## English

### Changes

- macOS: the usage cards in the status menu and the menu bar panel are now glass, so the menu's translucency shows through them. On macOS 26 and later they use Liquid Glass; earlier systems get a see-through fill. With Reduce Transparency on, they stay solid.
- macOS: the Settings window no longer has a Liquid Glass option. The "Liquid glass" switch and its strength setting are removed from General. The header and pages are solid, and the sidebar is slightly see-through.

### Fixes

- Windows: English and other Latin-script languages rendered in Tahoma, because the requested font name never matched. They now use Segoe UI Variable on Windows 11 and Segoe UI on Windows 10. Bold text uses Segoe UI Semibold, so it looks lighter than in 1.7.0.

### Release verification

- macOS: the Swift test suite, the Python script tests and the release gate (`./script/verify_release_all.sh`) run before tagging. The GitHub release workflow builds the app, signs the Sparkle appcast and publishes SHA-256 checksums. Builds are ad-hoc signed and not notarized. If Gatekeeper blocks the first launch, right-click the app and choose **Open**.
- Windows: the Windows unit tests run as part of packaging, and a release dry run passed on Windows 11 before tagging. The Windows 10 font fallback has not been tested on Windows 10. The installer and executables are not Authenticode-signed yet, so SmartScreen may show "Windows protected your PC". Choose **More info → Run anyway**.

## 简体中文

### 改进

- macOS：状态栏菜单和菜单栏面板里的用量卡片改为玻璃效果，能透出菜单本身的半透明。macOS 26 及以上使用 Liquid Glass，更早的系统使用半透明填充；开启「降低透明度」时保持实心。
- macOS：设置窗口不再提供液态玻璃选项，「通用」里的「液态玻璃效果」开关和强度设置已移除。顶部和页面为实心，侧边栏略带透明。

### 修复

- Windows：英文等拉丁语系界面此前因字体名匹配不上而显示为 Tahoma，现在 Windows 11 使用 Segoe UI Variable，Windows 10 使用 Segoe UI。粗体改用 Segoe UI Semibold，看起来会比 1.7.0 细一些。

### 发布验证

- macOS：打 tag 前运行 Swift 测试、Python 脚本测试和发布检查脚本（`./script/verify_release_all.sh`）。GitHub 发布流程负责构建应用、为 Sparkle appcast 签名并发布 SHA-256 校验值。安装包使用 ad-hoc 签名，尚未公证；如果首次打开被 Gatekeeper 拦下，请右键点按应用并选择「打开」。
- Windows：打包时会运行 Windows 单元测试；打 tag 前已在 Windows 11 上完成一次发布演练。Windows 10 上的字体回退尚未在 Windows 10 上实测。安装程序和可执行文件暂未做 Authenticode 签名，SmartScreen 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。
