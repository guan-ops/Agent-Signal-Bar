# Agent Signal Bar v1.7.0

## English

### Highlights

- Redesigned, unified native macOS interface across the settings window, menu bar panel, floating light popovers and status bar icon. The new look follows the system appearance in both light and dark mode.
- Claude support now matches Codex: Claude Code and Claude Desktop sessions drive the light, with the same quota, token and floating badge views.
- The light can follow whichever agent is active automatically. Auto-follow is the default for new installs.

### Changes

- Settings are reorganized into Overview, Usage, Light, Connections, General, Debug and About. The Overview page shows the current light, the agent being followed and a pause/resume button.
- New Light page groups status bar, floating light, effects, rhythm and sound settings. A new **Single Lamp** status bar style shows one lamp in the current signal color.
- Light agent selection adds **Auto-follow**. When you pin one agent and it goes idle while another agent is working, the light can temporarily show the other agent ("Show Others While Idle", on by default). Auto-follow sticks with the current agent while it is still working at the same priority, so the light does not jump between agents.
- Claude usage: OAuth, CLI and optional web sources; quota windows, extra usage, balances and reset information; multi-account overview; local token history with daily, model, project and session details.
- Codex credits: when a quota window is exhausted and the account has a verified credit balance, the badge switches to the balance and switches back when the quota resets.
- Codex and Claude usage pages, menu panel and floating popovers now share the same components.
- Connections: hooks are installed by a native installer that keeps equivalent existing hooks, repairs outdated ones and preserves other tools' configuration. The bundled CLI adds `install-hooks`.
- Optional Claude Desktop response observer (Connections → Claude) to show working state for desktop conversations that do not emit hook events.

### Fixes

- Claude Desktop sessions were labeled as Claude CLI. The hook now detects Claude Desktop, VS Code and JetBrains entry points.
- Selecting only Claude still showed Codex state in the light summary.
- Installing hooks from an app running inside a DMG or under App Translocation produced hooks that stopped working after the DMG was ejected. The app now asks you to move it to Applications first.
- Codex Desktop logs with `originator=codex_work_desktop` were treated as VS Code.
- Repeated macOS keychain password prompts when reading Claude Code credentials.
- Clearing the usage cache could restore a stale remote Codex quota.
- Claude history scans no longer fail when a session file is deleted or still being written during the scan.
- Pausing monitoring now also stops Claude usage refreshes.
- A single failed tool step (for example `grep` returning 1, or Claude Code `PostToolUseFailure`) no longer turns the light red, because the agent keeps working. Turn-level failures such as `StopFailure` still show blocked.

### Release verification

- Swift test suite, Python script tests and the release gate (`./script/verify_release_all.sh`) are run before tagging. Signing, notarization and the Sparkle appcast are produced by the GitHub release workflow and checked separately.

## 简体中文

### 亮点

- 全新统一的原生 macOS 界面：设置窗口、菜单栏面板、悬浮灯弹窗和状态栏图标风格一致，跟随系统浅色/深色外观。
- Claude 支持与 Codex 对齐：Claude Code 和 Claude 桌面版会话都能驱动状态灯，并提供同样的额度、Token 和悬浮角标视图。
- 状态灯可以自动跟随正在运行的 Agent，新安装默认为「自动跟随」。

### 改进

- 设置重新整理为：概览、用量、灯效、连接、通用、调试、关于。概览页显示当前灯态、正在跟随的 Agent，并可一键暂停/恢复。
- 新增「灯效」页，集中状态栏、悬浮灯、动画效果、灯光节奏和声音设置；状态栏新增「单灯」样式，只显示一颗当前信号颜色的灯。
- 灯效 Agent 选择新增「自动跟随」。手动选定某个 Agent 后，如果它空闲而另一个 Agent 在运行，灯可以临时显示另一个 Agent（「空闲时显示其他 Agent」，默认开启）。自动跟随时，只要当前 Agent 仍以同等优先级运行，就不会来回切换。
- Claude 用量：支持 OAuth、CLI 和可选网页来源；显示额度窗口、额外用量、余额与重置信息、多账号概览，以及按日、模型、项目、会话展开的本机 Token 明细。
- Codex credits：额度窗口耗尽且账号有已验证的 credits 余额时，角标自动显示余额，额度恢复后切回。
- Codex 与 Claude 的用量页、菜单面板和悬浮弹窗共用同一套组件。
- 连接：改用原生 Hook 安装器，保留已有的等效 Hook、修复过期配置，并保留其他工具的配置；内置 CLI 新增 `install-hooks` 命令。
- 可选的 Claude 桌面版回复检测（连接 → Claude），用于不产生 Hook 事件的桌面对话。

### 修复

- Claude 桌面版会话被显示为 Claude CLI；Hook 现在能识别桌面版、VS Code 和 JetBrains 入口。
- 只选择 Claude 时，灯效摘要仍显示 Codex 的状态。
- 从 DMG 内或被 App Translocation 隔离的位置运行时安装 Hook，推出 DMG 后 Hook 失效；现在会提示先把应用移到「应用程序」文件夹。
- `originator=codex_work_desktop` 的 Codex 桌面版日志被识别为 VS Code。
- 读取 Claude Code 凭据时反复弹出钥匙串密码框。
- 清除用量缓存后可能恢复过期的远程 Codex 额度。
- 扫描期间会话文件被删除或仍在写入时，Claude 历史扫描不再失败。
- 暂停监控时同时停止 Claude 用量刷新。
- 单个工具步骤失败（例如 `grep` 未匹配返回 1，或 Claude Code 的 `PostToolUseFailure`）不再亮红灯，因为 Agent 会继续工作；整轮失败（如 `StopFailure`）仍显示阻塞。

### 发布验证

- 打 tag 前运行 Swift 测试、Python 脚本测试和发布检查脚本（`./script/verify_release_all.sh`）。签名、公证和 Sparkle appcast 由 GitHub 发布流程生成，另行核对。
