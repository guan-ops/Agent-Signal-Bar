# Agent Signal Bar v1.6.2

macOS 14+ · Apple Silicon + Intel · Build 23

## English

### Improvements

- Adds GPT-6.1 Sol to local Token history, session details and estimated costs, with its own amber orange chart color.
- Uses verified Standard rates of $2 input, $0.10 cached input and $10 output per million tokens. Above 272K input tokens, input/cache rates double and output rates increase by 1.5×; Fast uses 2× the applicable Standard rates. See the [official model pricing](https://developers.openai.com/api/docs/models/gpt-6.1-sol).
- Fixes underestimated GPT-5.5 and GPT-5.4 long-context costs when the external pricing catalog omits context tiers. Existing cost caches are recalculated on the next scan, including unchanged session logs.
- Preserves explicit catalog context rates and leaves costs unknown when no price is available, including unsupported Fast requests. Future models will continue to be adapted manually after their rates are verified.

### Upgrade notes

- Costs remain API-based USD estimates from local session input, cached input and output tokens, not subscription bills or Codex credit consumption. Historical estimates use the configured rates; separate cache-write charges, regional premiums and Ultrafast pricing are outside this estimate.
- Requires macOS 14 or later. Universal packages include Apple Silicon and Intel binaries, with both existing and universal Sparkle update feeds retained.
- This release uses ad-hoc signing. It is not Developer ID signed or Apple notarized.

## 简体中文

### 改进

- 本机 Token 历史、会话明细和费用估算新增 GPT-6.1 Sol，图表使用独立的琥珀橙色。
- 使用已核实的 Standard 单价：每百万 Token 输入 $2、缓存输入 $0.10、输出 $10。单次请求输入超过 272K 时，输入／缓存单价为 2 倍、输出单价为 1.5 倍；Fast 按适用的 Standard 费用计算为 2 倍。价格来源见 [官方模型文档](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。
- 修复外部价格目录缺少长上下文档位时，GPT-5.5 和 GPT-5.4 费用被低估的问题。旧费用缓存会在下次扫描重新计算，原始日志未变化也能更新。
- 保留目录明确提供的上下文费率；没有可用价格或不支持的 Fast 请求，费用保持未知。后续新模型仍在核实价格后手动适配。

### 升级说明

- 费用仍根据本机会话的输入、缓存输入和输出 Token，按 API 单价以美元估算，不等于订阅账单或 Codex 积分消耗。历史估算采用当前配置费率；单独的缓存写入费、地区附加费和 Ultrafast 定价不在此估算范围内。
- 支持 macOS 14 及以上；通用安装包包含 Apple Silicon 和 Intel 架构，保留已有及通用 Sparkle 更新源。
- 本版本使用 ad-hoc 签名，未进行 Developer ID 签名或 Apple notarization 公证。
