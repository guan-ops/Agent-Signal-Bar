# Agent Signal Bar v1.6.0

macOS 14+ · Apple Silicon + Intel · Build 21

## English

### Highlights

- Adds Claude Code integration: one-click installation with Anthropic's official installer, automatic browser authorization, account and subscription usage, local Token/cost estimates, and signal-light controls.
- Brings shared Codex/Claude usage summaries and 30-day Token charts to both the system menu and card panel.
- Adds collapsible Codex project and session details to Usage settings, with search, project filtering, and small batches of results.

### Improvements

- Shows local Token scan progress and completion while retaining confirmed results during refreshes.
- Keeps menu charts focused on Tokens and avoids embedded scrolling in menu summaries.
- Refines settings backgrounds, sidebar material, separators, and chart spacing. Chart details expand inline with content instead of using a floating overlay.
- Makes project, session, and Claude connection-setting headings clickable across the whole row.
- Supports optional claude-swap account lists and switching. Claude Desktop activity monitoring remains independent of Claude Code authorization.

### Fixes

- Improves Codex scan completion and reconciliation of history with live Token counters.
- Serializes concurrent state-file access within the same process to prevent lost signal updates.

### Upgrade notes and verification

- Claude account access uses Claude Code only; browser Cookie import is not included. Personal subscription authorization requires Claude Pro or Max. A Free account was blocked by the official authorization page during testing.
- One-click installation and automatic browser opening were tested with the real Claude Code installer. Successful paid-account OAuth usage retrieval has not yet been tested end to end; it is covered by isolated fixtures.
- Local Token totals are device-wide session estimates, not the selected account's subscription bill. Unknown costs are not treated as zero.
- Download publication requires the release workflow's tests, universal packaging, installation, signature, checksum, and both Sparkle-feed checks.
- This release is ad-hoc signed, not Developer ID signed or Apple notarized.

## 简体中文

### 亮点

- 新增 Claude Code 接入：使用 Anthropic 官方安装器一键安装、自动跳转浏览器授权、账号和订阅配额、本机 Token／费用估算及状态灯控制。
- 系统菜单与卡片面板共用 Codex／Claude 用量摘要，均显示近 30 天 Token 柱状图。
- 用量设置新增可折叠的 Codex 项目与会话明细，支持搜索、按项目筛选和分批显示。

### 改进

- 显示本机 Token 扫描进度和完成状态，刷新期间保留已确认结果。
- 菜单图表固定显示 Token，用量摘要不再使用内嵌滚动区域。
- 调整设置底色、侧栏材质、分隔线与图表留白；图表详情在原位置按内容展开，不使用浮层。
- 项目、会话与 Claude 接入设置的整行标题均可点击展开、收起。
- 支持可选的 claude-swap 账号列表与切换；Claude Desktop 活动监控独立于 Claude Code 授权。

### 修复

- 改善 Codex 扫描完成状态，以及历史数据和实时 Token 计数的核对。
- 串行处理同一进程内的并发状态文件访问，避免信号更新丢失。

### 升级说明与验证

- Claude 账号仅通过 Claude Code 接入，不包含浏览器 Cookie 导入。个人订阅授权需要 Pro 或 Max；实测 Free 账号被官方授权页限制。
- 已实测官方 Claude Code 一键安装及自动打开授权页面。付费账号 OAuth 配额读取尚未完成端到端实测，目前由隔离测试覆盖。
- 本机 Token 为设备上的会话汇总和费用估算，不等于所选账号的订阅账单；未知费用不会当作零。
- 下载文件发布前，发布流程要求通过测试、通用打包、安装、签名、校验和及两路 Sparkle 更新源检查。
- 本版本使用 ad-hoc 签名，未进行 Developer ID 签名或 Apple notarization 公证。
