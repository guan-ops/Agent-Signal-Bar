# Agent Signal Bar v1.6.1

macOS 14+ · Apple Silicon + Intel · Build 22

## English

### Highlights

- Adds GPT-6 Sol and Luna to local Token records and estimated costs, alongside Astra and the GPT-5.6 family.
- Refreshes model names and chart colors: Astra in violet, Sol in orange-red, and Luna in yellow, with distinct colors for other supported models.
- Adds a cost display currency dropdown matching the language and theme controls in General settings, with 17 currencies including USD, CNY and NZD. Daily exchange rates include a visible date and an offline cache.

### Fixes and improvements

- Fixes overlapping glass backgrounds and clipped content in the native status menu when usage updates change its height.
- Speeds up JSONL history reading and keeps confirmed usage visible while active sessions finish writing.
- Recovers supported paginated Codex histories without counting inherited responses twice. Conflicting records remain excluded from confirmed totals.
- Preserves paginated history during partial writes and restores it from cache when reopening the app. Detects rewrites that occur during prefix validation.
- Cancels obsolete Claude history scans and prevents cancelled work from replacing current results.
- Preserves command failure codes in the CLI wrapper and improves diagnostic export failure handling. Release checks can use isolated diagnostic data.

### Upgrade notes

- Costs are calculated in USD from local session records at the configured API rates, then displayed in your selected currency at the latest available daily rate. Historical totals use that same rate. They are not Codex subscription bills or credit consumption. Local Token history is shared across accounts on this device.
- Currency conversion uses [ExchangeRate-API](https://www.exchangerate-api.com). Cached rates retain their date; when no rate is available, costs remain labeled USD. Account extra usage retains its billing currency.
- Historical estimates are recalculated when the pricing policy changes. Unsupported Fast costs remain unknown; confirmed costs are retained separately.
- Chart colors follow the supplied artwork reference; they are not an official published hex-color specification.
- This build uses ad-hoc signing. It is not Developer ID signed or Apple notarized.

## 简体中文

### 亮点

- 本机 Token 记录和费用估算新增 GPT-6 Sol、Luna，并覆盖 Astra 和 GPT-5.6 系列。
- 统一模型名称与图表配色：Astra 使用紫色、Sol 使用橙红色、Luna 使用黄色，其他支持的模型也采用独立配色。
- 通用设置新增与语言、主题样式一致的费用货币下拉框，支持美元、人民币、新西兰元等 17 种货币；使用每日更新的汇率，显示汇率日期并支持离线缓存。

### 修复与改进

- 修复状态栏系统菜单在用量刷新、内容高度变化时出现的玻璃背景重叠与内容裁切。
- 加快 JSONL 历史读取，并在活跃会话尚未写完时保留已确认用量。
- 恢复符合条件的 Codex 分页历史，避免重复计算继承的响应；仍有记录冲突的数据不计入已确认总量。
- 修复分页日志写到一半时历史掉数、重启后分页历史缓存未显示，以及前缀校验期间改写文件可能漏检的问题。
- 取消已过期的 Claude 历史扫描，避免旧任务覆盖当前结果。
- CLI 包装器保留原命令的失败退出码，改善诊断导出失败处理，并为发布检查增加隔离诊断数据的选项。

### 升级说明

- 费用按当前配置的 API 单价以美元计算，再按最新可用的每日汇率换算为所选货币；历史汇总也使用该汇率。不等于 Codex 订阅账单或积分消耗。本机 Token 历史由这台设备上的账号共用。
- 汇率来自 [ExchangeRate-API](https://www.exchangerate-api.com)。离线时保留缓存汇率及日期；没有可用汇率时仍以 USD 标示。账号额外用量保留账单币种。
- 价格策略变化后会重新计算历史估算；不支持的 Fast 费用保持未知，可确认部分单独保留。
- 图表配色依据提供的人物插画参考，并非官方公开的十六进制色值规范。
- 本版本使用 ad-hoc 签名，未进行 Developer ID 签名或 Apple notarization 公证。
