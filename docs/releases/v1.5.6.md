# Agent Signal Bar v1.5.6

## English

### Highlights

- Makes the 30-day Token usage chart respond smoothly when moving the pointer across bars, including days split across multiple models.
- Uses a slim, auto-hiding overlay scrollbar that no longer shifts the Settings content width when it appears.
- Adjusts the Settings window to 540 × 780 so the Usage page shows the complete Token usage card in one screen with a balanced bottom margin.

### Fixes

- Keeps the Token chart detail area at a stable height while hovering, preventing the scrollbar and pointer target from repeatedly changing layout.
- Preserves vertical scrolling as a fallback when account details, errors, or accessibility content need additional space.

### Release verification

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/package_release.sh`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/verify_release_all.sh --skip-package`
- Universal binaries were verified for both Apple Silicon and Intel Mac architectures.

## 简体中文

### 亮点

- 鼠标在近 30 天 Token 用量柱形图上移动时保持流畅，包括同一天由多个模型分段显示的情况。
- 使用纤细、自动隐藏的浮层滚动条，滚动条出现时不再挤压设置页面内容宽度。
- 将设置窗口调整为 540 × 780，使“用量”页面能够在一屏内完整显示 Token 使用卡片，并保留均衡的底部边距。

### 修复

- 悬停时保持 Token 图表详情区域高度稳定，避免滚动条和鼠标命中区域反复触发布局变化。
- 账户详情、错误信息或辅助功能内容需要更多空间时，仍保留纵向滚动作为兜底。

### 发布验证

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/package_release.sh`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/verify_release_all.sh --skip-package`
- 已确认 universal 二进制同时包含 Apple Silicon 和 Intel Mac 架构。
