# Agent Signal Bar v1.5.8

## English

### Highlights

- Codex reauthentication now recognizes the CLI bundled with ChatGPT.app.
- Opening Token details no longer makes today's Token total drop to zero or hides the badge, and today's cost updates after scanning.

### Upgrade note

- The first launch after updating may rebuild the Token and cost cache once. Details can briefly show `calculating…`; Codex session history is not changed.

### Release verification

- 321 Swift tests passed with 0 failures.
- Release build and local integrations passed.
- Universal Apple Silicon and Intel Mac artifacts are verified by the release workflow.
- This release is ad-hoc signed and is not notarized.

## 简体中文

### 亮点

- Codex 重新认证现在可以识别 ChatGPT.app 内置的 CLI。
- 打开 Token 详情不再导致今日 Token 归零或角标消失，扫描完成后会更新今日费用。

### 升级说明

- 更新后的首次启动可能重建一次 Token 和费用缓存，详情可短暂显示“正在计算…”，不会修改 Codex 会话历史。

### 发布验证

- 321 项 Swift 测试全部通过，0 项失败。
- Release 构建和本地集成验证通过。
- 发布工作流会验证同时支持 Apple Silicon 和 Intel Mac 的 universal 产物。
- 本版本使用 ad-hoc 签名，尚未进行 notarization 公证。
