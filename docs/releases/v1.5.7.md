# Agent Signal Bar v1.5.7

## English

### Highlights

- Adapts Codex quota presentation to weekly-only responses: when OpenAI returns one weekly window, Agent Signal Bar shows it once instead of repeating it as both 5-hour and weekly quota.
- Adds Small, Default, and Large floating-signal presets for both horizontal and vertical layouts. Free resizing remains available and is identified as Custom.
- Adds a visible explanation under New Zealand original mode so its crossing cadence and automatic sound selection are clear.

### Improvements

- Separates status-bar icon sizing from floating-signal sizing, so status-bar-specific controls no longer resize the desktop floating signal.
- Shows special status-bar size controls only when their style and direction apply.
- Makes the large vertical status-bar lamp unambiguously larger than the default footprint.
- Adds localized floating-signal size labels and guidance across the supported app languages.
- Hardens local hook path resolution and GitHub automation configuration.

### Fixes

- Removes duplicated weekly quota rows from the floating badge popover, Usage page, and native status-bar menu.
- Fixes the inverted floating-signal size behavior where selecting Large could make a vertical lamp smaller than Default.
- Keeps legacy 5-hour plus weekly quota responses working as two distinct windows.

### Release verification

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/package_release.sh`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/verify_release_all.sh --skip-package`
- Universal binaries were verified for both Apple Silicon and Intel Mac architectures.
- This release is ad-hoc signed and is not notarized.

## 简体中文

### 亮点

- 适配 Codex 仅返回周额度的情况：当 OpenAI 只返回一个周额度周期时，Agent Signal Bar 只显示一次，不再把它重复显示为 5 小时和一周额度。
- 为横向和竖向悬浮灯新增“小 / 默认 / 大”尺寸预设；继续支持自由拖动缩放，并将拖动后的尺寸标记为“自定义”。
- 在“新西兰原版模式”下增加可见说明，明确展示行人信号灯节奏和自动切换声音的行为。

### 改进

- 分离状态栏图标尺寸和桌面悬浮灯尺寸，状态栏专用控制不再改变悬浮灯。
- 状态栏特殊尺寸选项只在对应风格和方向下显示。
- 调整竖向状态栏灯牌的“大”尺寸，使其整体明确大于默认尺寸。
- 为所有已支持的 App 语言补充悬浮灯尺寸标签和说明。
- 加固本地 Hook 路径解析和 GitHub 自动化配置。

### 修复

- 移除悬浮额度弹层、“用量”页面和原生状态栏菜单中重复的周额度。
- 修复竖向悬浮灯选择“大”后反而小于“默认”的尺寸映射错误。
- 保持旧的“5 小时 + 一周”双额度响应继续显示为两个独立周期。

### 发布验证

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/package_release.sh`
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./script/verify_release_all.sh --skip-package`
- 已确认 universal 二进制同时包含 Apple Silicon 和 Intel Mac 架构。
- 本版本使用 ad-hoc 签名，尚未进行 notarization 公证。
