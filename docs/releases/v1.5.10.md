# Agent Signal Bar v1.5.10

macOS 14+ · Apple Silicon + Intel · Build 20

## English

### Highlights

- Adds built-in GPT-6 Astra cost estimates, including cached input, long-context requests, and Priority processing.
- Improves Codex usage synchronization while active sessions continue writing logs, reducing interruptions to history updates.
- Gives GPT-6 Astra and GPT-5.6 Sol, Terra, and Luna distinct names, colors, and ordering in usage charts.

### Improvements

- Reads a fixed snapshot of each Codex log so a scan can finish while new records arrive. Later records are picked up on subsequent refreshes.
- Shows a syncing message and retries automatically when session history changes during scanning, while retaining confirmed usage and live counters.
- Rebuilds daily usage caches when the system time zone or calendar changes, keeping daily totals aligned with the current local date settings.
- Removes raw local file paths from Token history scan error messages.

### Fixes

- Validates the scanned portion of session logs before accepting results, rejecting rewritten, truncated, or replaced history while allowing new records to be appended.
- Restores the saved account list if removing the active Codex account fails while updating active authentication, preserving credentials for recovery.
- Cleans up temporary login directories when authentication parsing or account saving fails.
- Bounds timeout cleanup for Codex login, CLI status checks, Hook operations, and diagnostics export, including subprocesses that ignore a normal termination request.
- Uses the running app bundle's version and build for release identity, preventing stale neighboring release metadata from overriding the displayed version.
- Corrects CI shell syntax checks so every script in the release script directory is checked individually.

### Upgrade notes

- The first refresh may rebuild older usage caches. Daily totals can move between dates after a time-zone or calendar change; original Codex session logs are not rewritten or deleted.
- Cost values are estimates derived from local session records and pricing rules, not an account billing statement.

### Release verification

- Local verification on September 5, 2026: 459 Swift tests passed with 0 failures.

- Regression coverage includes Astra pricing boundaries, concurrent log changes, synchronization messaging, cache day context, account failure recovery, subprocess termination, and release identity.
- Before downloadable assets are published, the release workflow requires universal packaging, architecture and installation checks, CLI/Hook integration, signatures, checksums, and both Sparkle feeds.
- This release uses ad-hoc signing and is not Developer ID signed or Apple notarized.

## 简体中文

### 亮点

- 新增 GPT-6 Astra 内置费用估算，支持缓存输入、长上下文请求及 Priority 处理模式。
- 改善 Codex 活跃会话持续写入日志时的用量同步，减少历史用量更新中断。
- 为 GPT-6 Astra 和 GPT-5.6 Sol、Terra、Luna 提供独立的图表名称、颜色与展示顺序。

### 改进

- 使用每份 Codex 日志的固定快照进行扫描，让扫描在新记录持续写入时也能完成；后续新增记录会在接下来的刷新中读取。
- 扫描期间会话历史发生变化时，显示同步提示并自动重试，同时保留已确认用量和实时计数。
- 系统时区或日历设置变化后，重新构建每日用量缓存，使每日统计与当前本地日期设置保持一致。
- Token 历史扫描错误提示不再直接显示本地文件路径。

### 修复

- 接受扫描结果前核验已读取的日志内容：允许正常追加新记录，对已读取历史被改写、截断或替换的情况拒绝采用结果。
- 删除当前 Codex 账户时，如果更新活动认证失败，恢复已保存账户列表并保留凭据，便于恢复操作。
- 登录期间解析认证信息或保存账户失败时，清理临时登录目录。
- 为 Codex 登录、CLI 状态检查、Hook 操作及诊断导出的超时清理设置等待上限，避免子进程忽略正常终止请求后一直等待。
- 优先使用正在运行的 App 自身版本号与构建号，避免邻近的旧发布元数据覆盖版本显示。
- 修正 CI 中的 Shell 语法检查，逐个检查发布脚本目录中的所有脚本。

### 升级说明

- 更新后的首次刷新可能重新构建旧用量缓存。时区或日历变化后，部分用量可能重新归入对应日期；不会改写或删除 Codex 原始会话日志。
- 费用是根据本机会话记录和定价规则计算的估算值，不代表账户实际账单。

### 发布验证

- 2026 年 9 月 5 日本地验证：459 项 Swift 测试通过，0 项失败。

- 回归测试覆盖 Astra 定价边界、日志并发变化、同步提示、缓存日期环境、账户失败恢复、子进程终止及发布版本识别。
- 下载文件发布前，发布流程要求完成通用打包、架构与安装验证、CLI/Hook 集成、签名、校验和及两路 Sparkle 更新源检查。
- 本版本使用 ad-hoc 签名，未进行 Developer ID 签名或 Apple notarization 公证。
